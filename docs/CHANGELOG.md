## 里程碑 M0–M7

| 里程碑 | 做了什么 | 完成 |
|---|------|:--:|
| **M0** | 项目文件格式契约:一个项目有哪些文件、每份装什么、谁写谁读;schema + 示例 + Rust 类型三件套互钉,一条 `vidbrief init` 建出标准项目 | 09-24 |
| **M1** | 步 1 打通:差帧曲线、密集区、精确抽帧、转录,命令行能跑 | 09-24 |

| **M3** | 挂上 MCP,agent 能调用工具 | 09-25 |
| **M4** | 校准迭代:改错字、补漏图;靠四轮真 agent 联调把「门」调对 | 09-25 |
| **M5** | 总结:agent 探索材料、按需补图,出一份结构化总结 | 09-25 |

| **M7** | 收尾:边角情况清干净,收官 | 09-27 |
